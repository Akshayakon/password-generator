# Password Generator

A simple command-line password generator in Python. Choose the length and which character types to include (letters, digits, symbols). Uses the `secrets` module for secure random generation.

## Usage

```
python password_generator.py
```

Example:

```
Password length: 12
Include letters? (y/n): y
Include digits? (y/n): y
Include symbols? (y/n): n
Password: aB3kQ9xLm2Zp
```

## Requirements

Python 3 (no extra packages needed).
